# Interpreting the channels

| Channel | What to inspect | Caution |
|---|---|---|
| Vibration X | Sharp spikes and sustained excursions | A single sample alone does not establish a fault |
| Vibration Y | Whether events coincide with X | Shared timing can indicate a common disturbance |
| Bearing temperature | Gradual rises and sustained elevation | Thermal response can lag mechanical changes |
| Shaft RPM | Oscillation or loss of stability | Speed changes can influence vibration measurements |

The bundled dataset is synthetic, sampled at one-minute intervals over 24 hours. Inspect baseline behavior before narrowing the brush. Correlation across channels is useful context, not proof of causation.

## Review checklist
- Compare the event with the preceding baseline.
- Check the duration, not only peak magnitude.
- Look for simultaneous changes in other channels.
- Separate measured values from generated hypotheses.
