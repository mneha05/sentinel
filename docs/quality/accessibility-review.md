# Accessibility review

Regression-review checklist for Sentinel's synthetic sensor telemetry demonstration.

Ensure buttons have accessible names, error banners can be announced, and status is not conveyed by color alone. Check chart alternatives for keyboard and screen-reader users. Document unsupported interactions as known limitations.

## Capture evidence
- Commit SHA, browser, and viewport
- Reproduction steps and sample range
- Expected behavior versus observed result
- Screenshots or test logs and remediation owner
