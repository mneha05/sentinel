# Analysis fallback

Regression-review checklist for Sentinel's synthetic sensor telemetry demonstration.

Test missing API key, provider timeout, invalid JSON, and schema-invalid payloads. Confirm the UI still renders an explicitly fallback-generated brief. Record whether the UI distinguishes model output from mock output.

## Capture evidence
- Commit SHA, browser, and viewport
- Reproduction steps and sample range
- Expected behavior versus observed result
- Screenshots or test logs and remediation owner
