# Demo release

Regression-review checklist for Sentinel's synthetic sensor telemetry demonstration.

Before presenting, run lint and build, inspect browser console, exercise brush and filters, test analysis fallback, and confirm live deployment matches the intended commit. Include a disclosure that all default telemetry is synthetic.

## Capture evidence
- Commit SHA, browser, and viewport
- Reproduction steps and sample range
- Expected behavior versus observed result
- Screenshots or test logs and remediation owner
