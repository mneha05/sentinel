# Hypothesis review

Regression-review checklist for Sentinel's synthetic sensor telemetry demonstration.

Separate measured signal changes from physical-fault hypotheses. Request evidence for each ranked hypothesis, then list plausible alternative explanations. Synthetic injections should not be mistaken for validated physical root causes.

## Capture evidence
- Commit SHA, browser, and viewport
- Reproduction steps and sample range
- Expected behavior versus observed result
- Screenshots or test logs and remediation owner
